# Security Policy

## Responsible Usage & Disclaimer

CUPP is designed for authorized penetration testing, security auditing, and educational research purposes only. 
- Do **not** use this tool for unauthorized target cracking or profile compilation.
- The repository authors are not liable for any misuse or damage caused by this software.

## Supported Versions

Only the latest stable release on the `master` branch is supported with security updates.

## Reporting a Vulnerability

If you identify a security vulnerability in the CUPP code (e.g. unsafe profile parsing, command line injection vectors, or memory leak exceptions), please do **not** open a public issue.

Please report vulnerabilities privately by emailing the repository owner or using GitHub's private vulnerability reporting feature.

We will review your submission and release a patch swiftly.
